# 竞品与数据源初查

核查日期：2026-09-14。范围为官方页面初查，不是完整市场研究，未测量用户量或大陆网络可达性。

| 对象 | 本次确认 | 对项目的影响 |
|---|---|---|
| [Yumefumi](https://www.yumefumi.com/) | 官方展示视觉小说记录与 Route maps | 路线记录已有产品，逐步选项导航仍需实际体验对比 |
| [VNDB API](https://api.vndb.org/kana) | 提供 VN、角色等资料查询及用户列表接口 | 可作为元数据候选；API 不等于可直接获得可靠交互攻略 |
| [月幕开放 API](https://www.ymgal.games/developer) | 有开发文档、OAuth2 认证说明及项目标注月幕的要求 | 接入前明确可用字段、认证、缓存和内容许可 |
| [CnGal 开放平台](https://open.cngal.org/) | 提供对外 API 文档入口 | 中文资料候选；需逐项确认覆盖范围和使用条款 |

不能由以上初查得出“国内没有竞品”或“英文网站必须翻墙”。聊天提及的 GameStoryLog、Kaguya、QuestCLAW 保留为后续调查线索，尚未独立核查，未纳入已确认对比。

## 下一轮验证

- 选择实际作品，走完竞品的搜索、选角色、当前选项提示、恢复进度全流程，记录可复现结果。
- 搜索中文无剧透交互攻略，比较具体行为，而不只比较首页宣传。
- 在不同大陆运营商网络实测站点和依赖资源；海外环境的访问结果不作大陆结论。
- 对元数据供应商记录认证、速率、缓存、归属标注及各字段许可；封面和正文不能随 API 一起推定授权。
- 对一条真实路线统计录入与复核耗时，以此决定第二部作品扩充节奏。
