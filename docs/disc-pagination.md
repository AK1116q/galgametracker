# 光盘分页与作品信息

2026-10-03。首页每页 8 部，保留完整作品目录搜索。滚轮／拖动期间淡出首页 UI，停止输入至少 420ms 且光盘回稳后恢复；键盘 Tab 可提前恢复界面。分页按钮与 PageUp / PageDown 切换整页，从攻略返回时定位作品所在页。

## 参考与实现

实际观察了 [Ravi Klaassens 的 A24 站点](https://a24.raviklaassens.com/) Films → Television 的过程，并查看浏览器公开加载的动画配置：退出 500ms、进入 1050ms、焦点盘放大 1.45 倍，其他盘延后展开。

本站用自写 Web Animations 与现有 CSS 光盘实现这一顺序，不打包参考站脚本、电影图片或 Three.js。它的 WebGL 材质、灯光、透视与本站 CSS 光盘不同，因此不是像素级完全复刻。分页时最多渲染 8 张盘，仅预解码新页附近 3 张封面；减少动态效果偏好直接切页。连续翻页在当前过渡结束前被锁定，避免动画叠加与页码错乱。

## 评分与简评

16 部作品评分均取自 Bangumi 公开 API，逐项保留条目 ID、评分人数、请求来源与核对日期，见 [gallery-metadata.json](../src/gallery-metadata.json)。前台不请求 Bangumi，不读取访客的第三方账户，也不把 VNDB 分数混用成 Bangumi 分数。

- 白色相簿2使用 CC 条目（22290，含 Coda），前台标识为「Bangumi · CC」，不是 IC / 全集平均分。
- 苍之彼方的四重奏使用游戏原作条目 76912，不使用动画或 EXTRA 的评分。
- DRACU-RIOT! 使用原作条目评分，攻略本身仍标注 QHD 适用版本。
- 短评为本站自行整理的无剧透简评，不是引用 Bangumi 用户评论，也不表示实机通关。
- 分数为注明日期的快照，不宣称实时；更新时应重新确认同一条目，不能用别的版本顶替。

标题使用 [Noto Serif SC](https://github.com/google/fonts/tree/main/ofl/notoserifsc) 600 字重的本地字符子集（约 66 KB），许可随字体置于 `public/fonts/OFL-NotoSerifSC.txt`。其余字形与未来作品名称使用系统衬线字体回退。

首页排版按视口高度分配光盘与文字空间：桌面标题最大 84px，评分最大 72px，简评最大 24px；评分和简评在标题下方并排。侧边光盘抬高，避免挡住长作品名。手机标题 32–42px，评分与简评上下排列，矮屏另行收紧间距。仅调整现有布局与光盘位移，不增加动画库或运行时测量。
