## 用户明确表达的方向

1. 服务有特定兴趣和需求的小群体，不局限于留学生。
2. 初期不依赖用户之间互动；一个人使用也有价值。
3. 对 Galgame 剧情路线记录器感兴趣，自己也有查路线需求。
4. 最大顾虑是无法玩遍全部作品，以及收集路线的工作量。
5. 关心已有竞品、面向大陆中文玩家的便利性，以及产品宣传。

## 对话提出、纳入规划的建议

- 定位逐渐从记录器收敛到中文、无剧透、逐步交互的路线助手。
- 关键闭环：游戏 → 版本 → 目标 → 当前选择 → 推荐 → 玩家确认 → 保存 → 结局记录。
- 路线逻辑与游戏基础资料分离；只收集必要选项及条件，不抄录完整剧情。
- 先验证少数作品的体验，再扩充数据；投稿需要审核。
- AI 只能辅助提取已有材料，人工确认后才能进入发布流程。
- 中文别名、不同汉化文本和版本差异是重要设计输入。
- 从少量真实玩家测试开始，以重复使用和实际导航成功衡量效果。
