# 性能与隐私验证

## 2026-09-24 光盘界面

- 六部作品以本地封面合成透视光盘；没有增加运行时依赖。每帧仅修改 transform / opacity / visibility，不读取布局，不逐帧更新 React 状态。位移按实际时间插值，支持高刷新率屏幕。
- 静止后停止 requestAnimationFrame；光盘区域离屏、页面隐藏时停止调度。离开游戏库时释放观察器、事件和帧任务。手机保留纵向原生滚动，横向拖动光盘，滚轮到边界后允许离开区域。
- 页面使用 180–280ms View Transition；旧浏览器回退为标题等局部过渡。连续导航以最后一次请求为准，浏览器历史、播放器 DOM 和本地记录保持原有行为。
- 每次刷新播放约 1.85 秒开场，支持跳过；系统减少动态效果时不播放开场和自动插值动画。
- 生产构建主 JS 约 348.53 KB（gzip 57.69 KB），React 独立包 218.84 KB（gzip 68.27 KB）。音乐继续按需加载，默认没有外部媒体、统计、远程字体请求。

### 同环境对照

Windows、Edge 153.0.4234.48、headless、1440×900；生产预览和参考站顺序测量，没有并行运行回归测试。页面加载及开场结束后采样 6 秒，发出 5 次、每次间隔 900ms 的滚轮手势。运行 `node scripts/measure-motion.mjs --reference` 可复测，结果与画面写入忽略提交的 `.artifacts/`。

| 指标               |  本站 | A24 参考站 |
| ------------------ | ----: | ---------: |
| rAF 间隔中位数     | 4.2ms |      4.2ms |
| rAF 间隔 P95       | 4.3ms |      4.3ms |
| 超过 33.4ms 的间隔 |     0 |          2 |
| 超过 50ms 的间隔   |     0 |          0 |
| 主线程长任务       |     0 |          0 |

这是一次本机诊断，并非真实手机 FPS、渲染合成帧率或所有设备都相同的承诺。视觉相似度也不是源码一致：参考站使用 canvas，本实现使用 CSS 3D 和 DOM。网络加载耗时不属于这组开场后测量。

验证：40 项数据/逻辑测试；42 项桌面与移动浏览器测试，含光盘方向键、回车、点击、横向拖动、细小滚轮增量、搜索恢复、返回原作品、刷新重播和全部旧攻略功能。最后的拖动跟随调整另重跑 6 项光盘交互测试。

## 历史记录

2026-09-18，Windows Edge 本地生产构建：

- 五部作品加入后，未优化主 JS 为 595.69 KB，gzip 145.21 KB。
- 改为构建时生成 JSON Schema 校验器，仍保留所有数据校验和错误分支；避免浏览器加载完整 Ajv 编译器和动态生成函数。`npm run check` 检查生成文件与 Schema 一致。
- React / React DOM 独立缓存，带 hash 的 `/assets` 使用一年 immutable 缓存；HTML 不设长期缓存。
- 加入音乐后，首屏 JS 合计约 540 KB，gzip 116 KB；音乐面板另约 2.37 KB / gzip 1.32 KB，仅主动打开时下载。YouTube iframe 要第二次明确点击才创建。相较新增作品后优化前，首屏 gzip 减少约 20%。
- 路线计算按数据与目标缓存。长路线不再整体作为动画图层；仅标题、篇章和目标区域执行 220ms 的 transform/opacity 过渡。路线节点启用离屏渲染跳过。
- 开场动画每次刷新或重新打开页面都播放，沿用参考项目 2.85 秒节奏，可跳过；尊重系统 `prefers-reduced-motion`，页面不可见时暂停环境动画。
- 未接入注册 SDK、第三方统计、远程字体或自动播放。CSP 禁止 eval、对象插件及非本站脚本，仅允许主动启用的 YouTube 隐私增强播放器 iframe。

测试包含桌面与移动尺寸、减少动态效果、首次不请求外部媒体、切页不重建 iframe、关闭播放器移除 iframe、导入损坏数据及刷新后恢复游客收藏。

低速 CPU 模拟仍可能在首次布局中文长攻略时产生较长任务。优化降低了大图层与同步布局开销，但本地自动化不能保证所有设备、网络和第三方播放器都不掉帧；不能把 headless 浏览器的 rAF 频率作为真实手机帧率承诺。
