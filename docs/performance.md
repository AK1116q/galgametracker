# 性能与隐私验证

2026-09-18，Windows Edge 本地生产构建：

- 五部作品加入后，未优化主 JS 为 595.69 KB，gzip 145.21 KB。
- 改为构建时生成 JSON Schema 校验器，仍保留所有数据校验和错误分支；避免浏览器加载完整 Ajv 编译器和动态生成函数。`npm run check` 检查生成文件与 Schema 一致。
- React / React DOM 独立缓存，带 hash 的 `/assets` 使用一年 immutable 缓存；HTML 不设长期缓存。
- 加入音乐后，首屏 JS 合计约 540 KB，gzip 116 KB；音乐面板另约 2.37 KB / gzip 1.32 KB，仅主动打开时下载。YouTube iframe 要第二次明确点击才创建。相较新增作品后优化前，首屏 gzip 减少约 20%。
- 路线计算按数据与目标缓存。长路线不再整体作为动画图层；仅标题、篇章和目标区域执行 220ms 的 transform/opacity 过渡。路线节点启用离屏渲染跳过。
- 开场动画每次刷新或重新打开页面都播放，沿用参考项目 2.85 秒节奏，可跳过；尊重系统 `prefers-reduced-motion`，页面不可见时暂停环境动画。
- 未接入注册 SDK、第三方统计、远程字体或自动播放。CSP 禁止 eval、对象插件及非本站脚本，仅允许主动启用的 YouTube 隐私增强播放器 iframe。

测试包含桌面与移动尺寸、减少动态效果、首次不请求外部媒体、切页不重建 iframe、关闭播放器移除 iframe、导入损坏数据及刷新后恢复游客收藏。

低速 CPU 模拟仍可能在首次布局中文长攻略时产生较长任务。优化降低了大图层与同步布局开销，但本地自动化不能保证所有设备、网络和第三方播放器都不掉帧；不能把 headless 浏览器的 rAF 频率作为真实手机帧率承诺。
