# 动画与交互性能

2026-10-03。本次沿用原有光盘、唱盘与页面视觉。

## 改动

- 光盘只在运动时申请合成层，静止后释放；样式值未变化时不重复写入。屏外光盘无需常驻 `will-change`。
- 光盘物理在桌面最高 120 Hz、窄屏最高 60 Hz 更新，按实际时间积分。页面隐藏或打开目录时停止物理循环；唱盘离开可见区域也暂停。
- 页面沿用短 View Transition；不支持时，对小范围标题／内容提供淡入降级。快速连续导航保留最后目标，后台页面直接更新。
- 目录打开和关闭使用原生离散过渡；旧浏览器保留原有打开动画。关闭音乐面板立即请求暂停，再完成 160ms 淡出。
- 按钮、链接及摘要增加短回弹；展开信息与提示有轻量淡入。反馈不延迟业务操作，也不覆盖光盘物理变换。
- 减少动态效果偏好关闭这些过渡；按钮保留键盘焦点样式。

目录过渡实现参考 [MDN dialog 动画说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog#animating_dialogs)。

## 同机测量

Windows Edge 无头浏览器，1440px 桌面和 390px 窄屏（4 倍 CPU 降速）。相同脚本移动光标 40 次，再等待物理回稳。基线为本次修改前生产构建，测量时未并行运行端到端测试。

| 指标                   | 桌面优化前 | 桌面优化后 | 窄屏降速前 | 窄屏降速后 |
| ---------------------- | ---------: | ---------: | ---------: | ---------: |
| 光盘 DOM 属性写入      |     10,693 |        336 |     10,710 |        183 |
| 主线程 TaskDuration 秒 |      0.591 |      0.531 |      2.059 |      1.820 |
| 样式重算秒             |      0.139 |      0.113 |      0.468 |      0.323 |
| 布局计算秒             |          0 |          0 |     0.0004 |          0 |
| 超过 34ms 的 rAF 间隔  |          0 |          0 |          0 |          0 |

这是单次受控样本，属性观察器本身有开销；不能当成真实手机性能、GPU 帧率或所有设备不卡顿的保证。rAF 间隔也不等于实际绘制帧率。自动回归另外检查静止期间零样式写入、合成提示释放、连续导航、目录过渡与减少动态效果。

复测：先 `npm run build`、`npm run preview -- --port 4173`，另开终端执行 `node scripts/benchmark-motion.mjs`。应在同一设备、相同浏览器和电源状态下比较，避免并行跑其他测试。
