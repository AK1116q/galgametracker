## 版本与资料差异

- PROLOGUE 完成后从 START 进入兰；兰之后开放绫／夜；绫之后开放希；夜之后开放白熊。
- 希之后开放直子／惠，白熊之后开放眠图标。眠图标对应独自用餐短篇，并非独立可攻略女主。
- 毕业篇要求兰、绫、夜、白熊、希完成。亲吻绫为第二结局，拥抱绫后再完成地点选择进入樱 TRUE。
- 序章地图访问顺序及 BAD END 有不同可行排列；本站固定采用誠也的一整套排列。两份攻略活动中部分文本属版本译名差异，按中文含义核对。
- 本页编号为本站步骤而非游戏日期。普通日常／演出差分与成就收集不在范围内。
