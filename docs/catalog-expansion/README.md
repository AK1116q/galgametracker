## 准确性边界

所有条目均为公开资料核对，未实机通关。部分路线的逐项选择只有一个可读取攻略来源，第二来源仅确认作品或版本；每部文档明确说明证据范围。中文为含义提示，不能保证与所有汉化补丁逐字一致。魔法使之夜限定 2012 PC 版，苍之彼方的四重奏限定 High Resolution 版，灰色的果实限定原 PC 版。

## 回退与维护

每个作品单独提交并推送。回退某部使用 `git revert <上表提交号>`，解决可能的封面索引冲突后运行 `npm run check`、`npm run test:e2e`，再推送并重新部署。应保留其他作品与用户本机数据，避免用 reset 覆盖后续提交。

画面复用现有光盘、唱盘与路线树组件。首页仅加载当前光盘附近的封面，作品目录按需加载。新十部暂未配置音乐，不沿用其他作品歌曲。
