- 回忆追加选项在咲、弥生、景子中任一条完成后才出现；首轮未出现时跳过该节点，不能误判选错。
- 有栖 TRUE 必须满足前置后从新游戏开始；舞亚／有栖短篇的最低解锁条件在来源中存在差异，本页明确提供完成上述任一条后的可用路径，不声称是最低条件。
- 本站保留 NookGaming 的一整组选法；日文攻略存在其他可到同一结局的钥匙／人物组合，不混用。
- 限定 2013 原作 PC 版／其英译版，不包含 Fragmentation Dream，REGRET END 的界面差异未核验。
