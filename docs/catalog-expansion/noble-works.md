# 贵族游戏

核对日期：2026-09-30。

用誠也的 SAVE01–07 继承关系恢复从头路径，核对萤的四个连续追加选择和首周目隐藏节点。NookGaming 独立确认六角色、三额外结局及萤解锁条件；其有效路径不同，未据此声称每个选项相同。

适用版本：PC 日文原版 / 主线含义提示。

- 覆盖六位角色和三个非角色结局；不覆盖差分 CG 或对话变体。
- 萤线需要先完成其他五位角色中的任意一条。四个追加选择必须连续满足；不要跳过。
- 濑奈路径中「在校舍内寻找」首次游玩不出现，可跳过；追加选择开放后应照此项选择。
- 两个攻略使用的好感组合不同，这里采用誠也完整路径，不混拼。三个非角色结局在资料中有 Normal / Bad 的命名差异，因此以触发位置区分。
