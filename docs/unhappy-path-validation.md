# 异常路径验证

验证日期：2026-10-15 至 2026-10-16。

## 覆盖范围

| 场景                                              | 预期行为                                                         |
| ------------------------------------------------- | ---------------------------------------------------------------- |
| 浏览器禁止读取存储                                | 攻略仍可阅读；原始备份按钮提示无法读取，不产生未捕获异常         |
| 存储容量已满                                      | 保存失败有提示，不显示成功、不改变已保存收藏                     |
| 空字符串、损坏 JSON、未来版本的本地备份           | 保留原始内容，阻止覆盖，可原样导出                               |
| 导入损坏、超限、引用无效或冲突的数据              | 整份导入被拒绝，原收藏和进度不变                                 |
| 文件读取期间用户继续收藏                          | 导入合并最新记录，保留读取期间的操作                             |
| 另一标签页更新、清空或写入损坏数据                | 正常更新及时同步；损坏更新保留内存中的最后有效副本供导出         |
| 另一标签页更新的通知尚未到达                      | 保存前比对存储快照，拒绝覆盖新记录并提示重试                     |
| 收到更新后、界面尚未重绘时点击旧按钮              | 拒绝基于旧记录构造的修改，提示确认后重试，保留另一标签页的新数据 |
| 畸形路径、未知攻略版本、脚本样式查询参数          | 不执行输入，不误指向其他版本，允许返回或重新选择                 |
| 链接的篇章与有效目标结局冲突                      | 以目标结局所属篇章显示，页面正文与标题保持一致                   |
| 导入来源包含无法解析的 HTTP(S) URL                | 在导入校验阶段拒绝，防止来源区域渲染崩溃                         |
| 封面请求失败或一直未结束                          | 不无限等待；仍可翻页、打开攻略、返回首页                         |
| 开场、翻页或光盘过渡动画被取消                    | 清理遮罩及交互锁，导航可继续                                     |
| 开场期间历史导航、页面隐藏/恢复或修改减少动态偏好 | 完成清理，避免旧动画锁住新页面；遵守减少动态设置                 |

## 自动验证

- `npm run check`：数据及 schema 校验、核心逻辑单元测试、TypeScript 检查、生产构建和静态页面生成。
- `npm run test:e2e`：桌面与手机视口的完整浏览器回归，包含原有正常流程及新增异常流程。
- 新增用例：`tests/unhappy-inputs.test.mjs`、`e2e/unhappy-storage.spec.ts`、`e2e/unhappy-navigation.spec.ts`、`e2e/unhappy-motion.spec.ts`。
- 每次 push / pull request 由 `.github/workflows/check.yml` 运行相同检查；失败时保留浏览器 trace。

存储故障、通知延迟、请求失败及生命周期中断使用隔离浏览器中的故障注入。测试会核对原始存储内容、实际 DOM 状态、可继续操作的结果，不仅检查提示文字。

## 验证边界

这些检查验证网站行为和数据保护，不代表已逐部实机验证游戏攻略，也不等于所有浏览器和真实移动设备都已测试。手机项目使用 Chromium 的移动视口模拟。

当前记录仍保存在用户浏览器。写入前快照比对能避免尚未收到通知的旧页面覆盖较新记录，但 localStorage 不提供跨进程原子事务；极短时间内完全同时写入仍不是事务级同步。网站没有账号服务或服务器存档恢复，导出备份仍是跨设备保留记录的方式。
